# Manga Helper

[![GitHub release](https://img.shields.io/github/v/release/FrostBy/manga-helper-standalone)](https://github.com/FrostBy/manga-helper-standalone/releases/latest)

**Русский** | [🇬🇧 English](README.md)

Кросс-платформенный трекер манги. Отслеживайте прогресс чтения на разных сайтах и быстро находите, где доступно больше глав.

## Возможности

- **Кросс-платформенный трекинг** — Смотрите количество глав с других сайтов, находясь на любимой платформе
- **Синхронизация прогресса** — Показывает ваш прогресс чтения с каждой платформы
- **Автопоиск** — Автоматически находит ту же мангу на других платформах по названию; обновление перепроверяет автоматическую привязку и заменяет или снимает неверную
- **Ручная привязка** — Вручную связывайте мангу между платформами, если автопоиск не нашёл
- **Пометка как недоступно** — Явно помечайте платформу как недоступную (например, заблокирована правообладателем); она уходит вниз списка и пропускается при авто-обновлении
- **Сравнение глав** — Подсвечивает платформы, где доступно больше глав; у лицензированных тайтлов MangaLib считаются все главы, а не только открытые
- **Статус загрузки** — Платформа, которую не удалось загрузить, помечается ⚠ вместо нуля; устаревшие по кэшу цифры приглушены до обновления
- **Зеркала** — Если сайт или его API заблокирован, запросы и ссылки MangaLib и Senkuro переключаются на рабочее зеркало; обновление снова начинает с основного адреса
- **Родной вид** — Кнопка, выпадающий список и спиннер загрузки выглядят как на самом сайте; список открывается при загрузке страницы манги
- **Поиск в popup** — Ищите мангу по всем платформам из popup расширения с обложками; результаты сгруппированы по сайтам (MangaLib / HentaiLib, Senkuro / Senkognito)
- **Отладочные логи** — Настраиваемый уровень логов (DEBUG/INFO/WARN/ERROR/OFF) в настройках popup
- **Кэширование** — Результаты кэшируются для минимизации запросов к API

## Установка

### Из исходников

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/FrostBy/manga-helper-standalone.git
   cd manga-helper-standalone
   ```

2. Установите зависимости:
   ```bash
   pnpm install
   ```

3. Соберите расширение:
   ```bash
   pnpm build
   ```

4. Загрузите в браузер:
   - **Chrome**: Перейдите в `chrome://extensions/`, включите режим разработчика, нажмите "Загрузить распакованное", выберите `.output/chrome-mv3`
   - **Firefox**: Перейдите в `about:debugging#/runtime/this-firefox`, нажмите "Загрузить временное дополнение", выберите любой файл в `.output/firefox-mv2`

### Разработка

```bash
# Запуск dev-сервера с hot reload
pnpm dev

# Firefox
pnpm dev:firefox

# Проверка типов
pnpm typecheck

# Самопроверки
pnpm test
```

## Использование

1. Перейдите на страницу манги на любой поддерживаемой платформе
2. Список "Другие сайты" открывается рядом с кнопкой закладки; кнопка его сворачивает и разворачивает
3. В каждой строке — число глав на платформе и в скобках ваш прогресс там
4. Подсвеченное число означает, что на этой платформе доступно больше глав; ⚠ — данные не удалось загрузить
5. Иконка обновления перепроверяет платформу, иконка редактирования — привязывает мангу вручную, если автопоиск не нашёл
